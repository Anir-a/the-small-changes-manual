# One Small Shift

**A little science. A smaller step. A day that fits.**

An independent educational comic about sleep, movement, focus, stress and connection. Created with AI-assisted writing and original AI-generated illustrations. Alex is fictional.

## Read it

The website is deployed through GitHub Pages from the `docs` directory. Source files are in `dist` during local development; the published `docs` copy is identical.

- Choose one of five starting points with scientific sources beside the claims.
- Follow Alex through an ordinary day, without a perfect transformation.
- Try a flexible four-week plan with a browser-local tracker.
- Read the illustrated PDF and evidence audit in `docs/downloads`.

## Evidence and purpose

This is general education, not medical advice, diagnosis or treatment. The four-week sequence is an original starter design, not a tested health intervention. Research summaries distinguish correlation from causation and broad evidence from exact starter exercises. No habit-formation deadline is promised.

Scientific sources and book influences: [SOURCES.md](SOURCES.md). Publication and reuse notes: [RIGHTS.md](RIGHTS.md). Educational purpose and attribution do not automatically authorise copying.

## Run locally

The page is buildless HTML, CSS and JavaScript. Serve the `docs` folder with any static server. There are no runtime dependencies, accounts, analytics or external font requests. Tracker marks stay in browser storage; ordinary hosting access logs may still exist.
